# Учебный проект - разбор CI/CD
Чтобы улучшить свои скиллы в сфере DevOps я занялся изучать CI/CD. 
## Немного теории
CI - Continuous Integration
Это непрерывная интеграция. Каждое вливание изменений в общую ветку автоматически собирается и тестируется. Цель - найти ошибку через минуты после коммита, а не через несколько дней при релизе.
CD - Continous Delivery | Continuous Deployment 

|  | Delivery | Deployment |
| :--- | :--- | :--- |
| Готовность к релизу | Каждый зелёный коммит можно выкатить | То же самое)) |
| Деплой в прод | По кнопке или апрува человека | Автоматически, без участия человека |
| Когда подходит | Есть требования к согласованию, регуляторка | Хорошее покрытие тестами и мониторинг |
